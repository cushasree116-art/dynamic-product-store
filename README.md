# 🛍️ Dynamic Product Store

## 📌 Project Overview
Dynamic Product Store is a responsive web application that fetches product details from a REST API and displays them dynamically using JavaScript DOM manipulation.

## ✨ Features
- 📦 Fetches products from a REST API
- 🔍 Search products by name
- 🗂️ Filter products by category
- ↕️ Sort products by price
- 🛒 Add and remove products from the cart
- 💾 Saves cart items using Local Storage
- ⏳ Displays loading messages
- ⚠️ Handles API errors
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- REST API
- DOM Manipulation
- Local Storage

## 🌐 API Integration
This project uses the Fake Store API to retrieve product information dynamically.

**API Endpoint:** https://fakestoreapi.com/products

The Fetch API with async/await is used to request product data.

The application displays product names, images, prices, and categories.

The `api.js` file handles API requests, while `app.js` displays the retrieved products on the webpage.
